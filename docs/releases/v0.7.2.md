# v0.7.2：无需 API，先直接使用

这一版不要求用户先申请或配置模型 API。第一次安装后，可以直接使用本地优先的英语学习能力；AI 只保留为按需增强项。

## 不配置 AI 也能使用

- 离线中英查词与英文相关近义词；
- 单词和句子发音；
- 单词本、多个好句收藏夹与本地搜索；
- macOS 15 及以上的 Apple 本机中英短语和句子翻译；
- 全局划词、选中即展示、临时暂停与权限诊断。

好处是没有模型 API 费用，基础查询不依赖项目服务端，选中文字也不会发送给模型服务。Apple 语言资源首次下载可能需要联网，下载后翻译由系统在设备端完成。

## 无 API 模式的限制

- 不提供结合“产品经理面试”“英文简历”等场景的 AI 改写；
- “这样表达”和开放式语法问答需要可选 AI 服务；
- Apple 本机翻译更适合一般句意理解，不能保证达到专业英文编辑或母语化润色水平；
- macOS 14 可以继续使用离线词典、近义词、发音和收藏，但 Apple 本机翻译要求 macOS 15 或更高版本。

## 可选配置 AI

需要场景化表达、AI 地道化或结构化语法解释时，可以在应用的“AI 服务（可选）”中填写自己的服务地址。应用不会把 API Key 打进安装包，AI 请求也只会在用户主动点击相关按钮后发生。

## 安装信息

- 应用版本：`0.7.2`
- 构建号：`13`
- 安装包：`Context-English-Assistant-v0.7.2-arm64.zip`
- 系统：macOS 14+，Apple Silicon（M1/M2/M3/M4）

当前公开测试包使用临时签名，尚未完成 Apple Developer ID 公证。首次启动请在 Finder 中右键应用并选择“打开”，再按引导授予辅助功能权限。

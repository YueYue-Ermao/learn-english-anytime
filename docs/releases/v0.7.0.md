# v0.7.0：视觉升级与自动本机翻译

发布日期：2026-10-12

## 本次更新

- 重做划词结果卡片，增加更清楚的标题、音标、来源状态、译文区域和主次操作。
- 用统一的色彩、卡片和图标按钮改进学习中心、“这样表达”和权限诊断窗口。
- 词典未命中的短语与短句现在会直接进入 Apple 本机翻译，不需要先看到“未收录”再点击第二次。
- 自动翻译限制在 280 个字符以内；单个未知词和长段落继续由用户手动决定是否翻译。
- 相同内容的本机译文在应用本次运行期间缓存，重复查询更快。
- 改进未安装中英语言包时的错误说明。
- 增加 Apple / Android 跨平台路线图和平台能力边界。

## 费用与隐私

- 离线词典、Apple 本机翻译、收藏和学习中心不需要项目 AI 服务。
- Apple Translation 在设备端处理正文；首次使用某个语言组合时可能需要联网下载语言包。
- `AI 地道化`、`这样表达`和`语法问答`仍是用户主动触发的可选能力，可能产生模型 API 费用。

## 系统要求

- macOS 14 或更高版本。
- Apple Silicon（M1/M2/M3/M4）。
- 自动句子翻译需要 macOS 15 或更高版本；macOS 14 仍可使用离线词典和收藏。

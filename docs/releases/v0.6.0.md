# Learn English Anytime v0.6.0

发布日期：2026-09-28

客户端版本：v0.6.0（build 10）

平台：macOS 14+ / Apple Silicon arm64

## 新功能

- 从纯菜单栏工具升级为普通本地 Mac 应用，启动后显示“英语学习中心”。
- 增加“我的单词本”，集中查看、搜索、朗读和复制单词或词组收藏。
- 增加多个“好句收藏夹”，支持新建、删除、搜索、手动添加、移动、朗读和复制句子。
- 收藏数据库升级到 v2；旧句子和场景表达自动进入“默认好句”，不清空已有收藏。
- 增加结构化“语法问答”，支持句子、具体问题和可选场景。
- “AI 服务设置”统一支持地道表达和语法问答。
- 保留全局划词、离线词典、Apple 本机翻译、发音、暂停和选中即展示。

## AI 使用边界

- 单词本、好句收藏、离线查词和 Apple 本机翻译不需要本项目 AI 服务。
- 语法问答、地道化表达和“这样表达”只在用户主动操作后请求配置的服务，可能产生 API 费用。
- API Key 只配置在用户自己的服务端，不进入桌面应用。

## 安装

1. 下载并解压 `Context-English-Assistant-v0.6.0-arm64.zip`。
2. 将应用移动到“应用程序”文件夹。
3. 首次启动若被拦截，在 Finder 中右键选择“打开”。
4. 按应用引导开启辅助功能权限并重新检测。

当前安装包使用临时签名，尚未完成 Apple Developer ID 公证。

# v0.7.1：离线相关近义词

发布日期：2026-10-13

## 本次更新

- 选中英文单词后，浮窗会在释义下方展示最多 8 个相关近义词。
- 近义词候选来自 Princeton WordNet 3.1，并结合常见词义和 ECDICT 词频排序。
- 变化形式可回退到原形的近义词，例如词典通过词形索引识别的单词仍能得到结果。
- 没有合适近义词时自动隐藏该区域，原有浮窗不会出现空卡片。
- 同义词表完全包含在离线数据库中，不联网、不调用项目 AI 服务，也不产生模型 API 费用。
- 应用继续兼容旧词典数据库；缺少同义词表不会影响查词、翻译、收藏或发音。

## 使用说明

像以前一样在网页、Office、Codex 或其他应用中选中英文单词。展开完整浮窗后，“相关近义词 · 请按语境选用”会出现在中文释义下方。

近义词表示词义相关，不代表任何句子中都可以直接替换。尤其是一个单词有多个词义时，请结合当前句子、词性和语气选择。

## 数据与隐私

- 释义与音标：ECDICT 离线数据库。
- 相关近义词：Princeton WordNet 3.1 离线派生关系。
- 基础查词、近义词、发音和收藏不需要 API Key。
- 数据来源与许可随应用保存在 `ThirdPartyLicenses` 目录。

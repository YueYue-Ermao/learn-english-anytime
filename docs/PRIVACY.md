# 隐私说明

本项目优先在用户的 Mac 上处理数据。

## 本地处理

以下功能不向 Learn English Anytime 项目服务发送内容：

- 离线英汉/汉英查词；
- 单词本和好句收藏夹；
- 系统语音朗读；
- macOS 15 及以上的 Apple 本机翻译（语言包由 macOS 管理）；
- 辅助功能权限检测。

收藏保存在 `~/Library/Application Support/Context English Assistant/user.sqlite3`。项目当前不提供云同步，也不采集分析遥测。

## 可选 AI 请求

只有用户主动点击“AI 地道化”“这样表达”或“语法问答”时，客户端才会向用户配置的服务地址发送请求。请求可能包含：

- 用户选中的词、短语或句子；
- 能可靠提取到的最小所在句；
- 用户手动输入的场景；
- 用户的语法问题。

客户端不会附加完整文档、URL、窗口标题、应用使用历史、收藏数据库或 API Key。开发服务设置 `store: false`，且代码本身不持久化请求正文；实际部署者仍需自行制定并公布日志、保留和第三方模型政策。

## 系统权限

应用使用 macOS 辅助功能权限读取当前选中的文本与选区位置。它不监控剪贴板，不截图，不做 OCR，不读取未被选中的完整文件。

## 使用者责任

不要把公司机密、个人敏感信息或受限文件发送给未经组织批准的 AI 服务。企业部署者应配置自己的网关、身份验证、脱敏规则和审计策略。
